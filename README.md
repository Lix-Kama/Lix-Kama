## Hello, I'm Salix Kamara 👋

I'm a **Cyber Security Analyst with 4+ years of experience**, focused on security operations, incident response, threat detection, vulnerability management, and cloud security.

I enjoy investigating security events, developing detection capabilities, working through hands-on security labs, and finding practical ways to improve security. I'm also exploring AI, digital forensics, and software development to build useful tools that solve everyday problems.

My goal is to combine practical security knowledge, continuous learning, and automation to help make digital environments more secure.
